Fundamentos

¿Qué son los datos y qué es una base de datos?

Foundations

What is data and what is a database?

Un dato es una representación registrable: un nombre, una fecha, una edad, el precio de un producto o la calificación de una película. Una base de datos organiza esos datos para almacenarlos, consultarlos, relacionarlos y actualizarlos.

A datum is a recordable representation: a name, a date, an age, a product price, or a movie rating. A database organizes data so it can be stored, queried, related, and updated.

Bases relacionales y no relacionales

No toda la información se organiza igual. El modelo se elige según el problema, las consultas y las reglas de consistencia.

Relational and Non-Relational Databases

Not all information is organized the same way. The model depends on the problem, the queries, and consistency rules.

Relacionales (SQL) Relational (SQL)

Organizan información en tablas conectadas por claves. Son muy usadas en matrículas, facturación, inventarios y transacciones.

They organize information in tables connected by keys. They are widely used for enrollment, billing, inventory, and transactions.

Relaciones y claves

Las claves permiten conectar tablas sin repetir todos los datos en cada registro.

Relationships and Keys

Keys connect tables without repeating all data in every record.

PK

La clave primaria identifica de forma única cada fila de una tabla.

The primary key uniquely identifies each row in a table.

FK

La clave foránea referencia una clave de otra tabla.

The foreign key references a key from another table.

1:N

Un cliente puede tener muchos pedidos; cada pedido pertenece a un cliente.

One customer can have many orders; each order belongs to one customer.

Importante: si `id_cliente = 1` aparece en dos pedidos, eso no es necesariamente un duplicado. Puede representar dos compras legítimas de la misma persona.

Important: if `customer_id = 1` appears in two orders, that is not necessarily a duplicate. It may represent two legitimate purchases by the same person.

Normalization: organizing to avoid problems

La normalización separa entidades y relaciones para reducir redundancias innecesarias. Evita errores de actualización, inserción y eliminación cuando un dato se repite sin control.

Normalization separates entities and relationships to reduce unnecessary redundancy. It prevents update, insertion, and deletion problems when data is repeated without control.

¿Qué es SQL?

SQL permite consultar, insertar, actualizar y eliminar información. En esta sesión trabajamos consultas sin modificar datos.

What is SQL?

SQL lets us query, insert, update, and delete information. In this session we query data without modifying it.

Una consulta básica responde: qué quiero ver, de qué tabla viene y qué condición debe cumplir.

A basic query answers: what I want to see, which table it comes from, and what condition it must satisfy.

SELECT name, city
FROM Customers
WHERE city = 'Tunja';

La convención de escribir `SELECT` y `FROM` en mayúsculas mejora la lectura. Para textos se usan comillas simples.

The convention of writing `SELECT` and `FROM` in uppercase improves readability. Text values use single quotes.

INNER JOIN: combining related information

`INNER JOIN` conserva las filas que encuentran coincidencia según la condición `ON`. Si una película no tiene fila relacionada en taquilla, no aparece en ese resultado.

`INNER JOIN` keeps rows that find a match according to the `ON` condition. If a movie has no related box-office row, it does not appear in that result.

Moviesid PK · title · director · year
BoxOfficemovie_id FK · rating · sales
ONMovies.id = BoxOffice.movie_id
INNER JOINSolo coincidenciasMatches only
SELECTTítulo, calificación, ventasTitle, rating, sales
SELECT Movies.title, BoxOffice.rating
FROM Movies
INNER JOIN BoxOffice
ON Movies.id = BoxOffice.movie_id;
SELECT Movies.title, BoxOffice.domestic_sales
FROM Movies
INNER JOIN BoxOffice
ON Movies.id = BoxOffice.movie_id
WHERE BoxOffice.domestic_sales > 200000000
ORDER BY BoxOffice.domestic_sales DESC;

Plantilla de consulta

No necesitas usar todas las cláusulas en cada consulta. Empieza por `SELECT` y `FROM`, y añade lo necesario.

Query Template

You do not need every clause in every query. Start with `SELECT` and `FROM`, then add what you need.

SELECT column1, column2
FROM table1
INNER JOIN table2
ON table1.id = table2.related_id
WHERE condition
ORDER BY column1 DESC
LIMIT 5;
