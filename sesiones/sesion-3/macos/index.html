Paso 3. Crear el Mapper

Step 3. Create the Mapper

import csv
import sys

lector = csv.reader(sys.stdin)

for fila in lector:
    if not fila or fila[0] == "id":
        continue
    red_social = fila[2].strip()
    if red_social:
        print("{}\t1".format(red_social))

Guarda el archivo con nano mapper.py. La primera columna es el encabezado id; la tercera contiene red_social.

Save this file with nano mapper.py. The first column is the id header; the third contains red_social.

Paso 4. Crear el Reducer

Step 4. Create the Reducer

import sys

red_actual = None
total = 0

for linea in sys.stdin:
    red, cantidad = linea.strip().split("\t")
    cantidad = int(cantidad)
    if red == red_actual:
        total += cantidad
    else:
        if red_actual is not None:
            print("{}\t{}".format(red_actual, total))
        red_actual = red
        total = cantidad

if red_actual is not None:
    print("{}\t{}".format(red_actual, total))

Guarda con nano reducer.py. Hadoop entrega al reducer los pares ya ordenados por clave.

Save with nano reducer.py. Hadoop gives the reducer pairs already sorted by key.

Paso 5. Probar y ejecutar Hadoop

Step 5. Test and run Hadoop

cat datos/comentarios.csv | python3 mapper.py | sort | python3 reducer.py
STREAMING_JAR="$(find "$HADOOP_HOME/share/hadoop/tools/lib" -name 'hadoop-streaming-*.jar' -print -quit)"
echo "$STREAMING_JAR"

hadoop jar "$STREAMING_JAR" \
  -D mapreduce.framework.name=local \
  -D fs.defaultFS=file:/// \
  -files mapper.py,reducer.py \
  -mapper "python3 mapper.py" \
  -reducer "python3 reducer.py" \
  -input datos/comentarios.csv \
  -output resultado_hadoop

Paso 3. Crear main.py

Step 3. Create main.py

from pyspark.sql import SparkSession
from pyspark.sql.functions import col, desc

spark = (SparkSession.builder
    .appName("ComentariosRedesSociales")
    .master("local[*]")
    .getOrCreate())
spark.sparkContext.setLogLevel("ERROR")

df = spark.read.csv("comentarios.csv", header=True,
                    inferSchema=True, encoding="UTF-8")

print("\nPRIMEROS COMENTARIOS")
df.show(5, truncate=False)
print("\nESTRUCTURA")
df.printSchema()
print("\nTOTAL DE COMENTARIOS")
print(df.count())

print("\nCOMENTARIOS POR RED SOCIAL")
df.groupBy("red_social").count().orderBy(desc("count")).show()

print("\nCOMENTARIOS SPAM")
df.filter(col("spam_referencial") == "Sí").show(truncate=False)

print("\nPRIORIDAD")
df.groupBy("prioridad_referencial").count().show()

spark.stop()
