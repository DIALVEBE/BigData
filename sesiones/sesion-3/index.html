Parte 1 · Apache Hadoop

Hadoop: almacenar y procesar a escala

Hadoop es un ecosistema, no una sola aplicación. Sus componentes separan almacenamiento, recursos y procesamiento.

Part 1 · Apache Hadoop

Hadoop: storage and processing at scale

Hadoop is an ecosystem, not one application. Its components separate storage, resources, and processing.

HDFS

Sistema de archivos distribuido. Divide archivos grandes en bloques, los replica y los distribuye. El NameNode conserva metadatos y los DataNodes almacenan bloques.

Distributed file system. It splits large files into blocks, replicates, and distributes them. The NameNode keeps metadata and DataNodes store blocks.

YARN

Administrador de recursos que decide dónde y con cuánta capacidad se ejecutan las aplicaciones del clúster.

Resource manager that decides where and with how much capacity cluster applications run.

MapReduce

Modelo que transforma registros en pares clave–valor, agrupa por clave y combina valores.

Model that transforms records into key-value pairs, groups by key, and combines values.

flowchart LR
  F[Archivo grande] --> B[Bloques]
  B --> N[NameNode: metadatos]
  B --> D1[DataNode A]
  B --> D2[DataNode B]
  D1 -. copias .-> D2
  RM[ResourceManager] --> T[Tareas MapReduce]

El clúster no es obligatorio para aprender

HDFS, YARN y varios nodos son importantes en producción, pero esta práctica usa modo local: un computador y archivos locales.

A cluster is not required to learn

HDFS, YARN, and multiple nodes matter in production, but this lab uses local mode: one computer and local files.

Escala: distribuir puede ayudar con mucho volumen, pero añade coordinación, red, particiones y tolerancia a fallos. Con diez filas no medimos rendimiento.

Scale: distribution can help with large volumes, but adds coordination, networking, partitions, and fault tolerance. With ten rows we are not measuring performance.

MapReduce explicado con sobres

Primero veremos un ejemplo distinto y luego aplicaremos la misma idea a los comentarios de redes sociales.

MapReduce explained with envelopes

First we will use a different example, then apply the same idea to social-media comments.

La pregunta: cuando hay muchos registros, ¿cómo convertimos miles de elementos pequeños en un resumen confiable? MapReduce divide el trabajo en una transformación, una organización intermedia y una agregación.

The question: when there are many records, how do we turn thousands of small items into a reliable summary? MapReduce divides the work into a transformation, an intermediate organization step, and an aggregation.

Ejemplo 1: contar palabras de una biblioteca

Supón que tenemos tres frases escritas en fichas:

  • datos abiertos
  • datos limpios
  • datos abiertos

Queremos saber cuántas veces aparece cada palabra, sin contar manualmente toda la caja de fichas.

Example 1: counting library words

Suppose we have three cards with these phrases:

  • open data
  • clean data
  • open data

We want to count each word without manually checking the whole box of cards.

EtapaQué ocurreStageWhat happens
MAPCada palabra produce (palabra, 1).MAPEach word produces (word, 1).
SHUFFLESe juntan todos los pares con la misma palabra.SHUFFLEAll pairs with the same word are grouped.
REDUCESe suman los valores de cada grupo.REDUCEValues in each group are added.
flowchart LR
  A[Three phrase cards] --> B[MAP: emit word, 1]
  B --> C[open 1 · data 1 · clean 1 · data 1 · open 1 · data 1]
  C --> D[SHUFFLE: group by word]
  D --> E[open: 1+1 = 2]
  D --> F[data: 1+1+1 = 3]
  D --> G[clean: 1]

Leer el ejemplo paso a paso

  1. MAP no decide el resultado final: solo identifica una palabra y emite una unidad.
  2. SHUFFLE funciona como una mesa que coloca juntos los sobres con la misma etiqueta.
  3. REDUCE recibe un grupo ya organizado y calcula 2, 3 o 1.

Read the example step by step

  1. MAP does not decide the final result: it identifies a word and emits one unit.
  2. SHUFFLE acts like a table that puts envelopes with the same label together.
  3. REDUCE receives an organized group and calculates 2, 3, or 1.

Ahora sí, nuestro caso: cambiaremos “palabra” por “red_social”. El mapper no cuenta Facebook por sí mismo; emite Facebook, 1 para cada fila. El shuffle junta esos pares y el reducer suma los unos.

Now our case: we replace “word” with “social network”. The mapper does not count Facebook by itself; it emits Facebook, 1 for each row. Shuffle groups the pairs and the reducer adds the ones.

¿Por qué el mapper emite 1?

Cada fila representa una ocurrencia. Seis filas de Facebook producen seis veces Facebook → 1; el reducer suma esos unos.

Why does the mapper emit 1?

Each row is one occurrence. Six Facebook rows produce six Facebook → 1 pairs; the reducer adds those ones.

Step 5. Create REDUCE

import sys

red_actual = None
total = 0

for linea in sys.stdin:
    red, cantidad = linea.strip().split("\t")
    cantidad = int(cantidad)
    if red == red_actual:
        total += cantidad
    else:
        if red_actual is not None:
            print(f"{red_actual}\t{total}")
        red_actual = red
        total = cantidad

if red_actual is not None:
    print(f"{red_actual}\t{total}")

Part 2 · Apache Spark

Spark: express analysis with DataFrames

Spark is a processing engine; PySpark is its Python interface.

Driver

Programa que crea SparkSession, construye el plan y coordina el trabajo.

Program that creates SparkSession, builds the plan, and coordinates the work.

Executors

Procesos que ejecutan tareas sobre particiones.

Processes that execute tasks over partitions.

Partitions

Fragmentos lógicos que pueden procesarse en paralelo.

Logical fragments that can be processed in parallel.

flowchart TB
  P[Programa Python] --> D[Driver / SparkSession]
  D --> L[Plan lógico]
  L --> X[Plan físico]
  X --> E1[Executor: particiones 1 y 2]
  X --> E2[Executor: particiones 3 y 4]
  E1 --> R[Resultado]
  E2 --> R

DataFrame

Tabla distribuible con filas, columnas y esquema. Spark puede optimizar filtros, agrupaciones y ordenamientos.

DataFrame

A distributable table with rows, columns, and a schema. Spark can optimize filters, groups, and sorting.

Evaluación diferida

select, filter y groupBy describen transformaciones. show, count y write activan el cálculo.

Lazy evaluation

select, filter, and groupBy describe transformations. show, count, and write trigger computation.

Spark no es HDFS: puede leer archivos locales, HDFS y otros orígenes, y ejecutarse localmente o en un clúster.

Spark is not HDFS: it can read local files, HDFS, and other sources, and run locally or on a cluster.

Paso 3. Crear main.py

Ejecuta nano main.py y pega:

Step 3. Create main.py

Run nano main.py and paste:

from pyspark.sql import SparkSession
from pyspark.sql.functions import col, count, desc, round as spark_round
from pyspark.sql.functions import sum as spark_sum, when

spark = (SparkSession.builder
    .appName("ComentariosRedesSociales")
    .master("local[*]")
    .getOrCreate())
spark.sparkContext.setLogLevel("ERROR")

df = spark.read.csv("src/spark_practica/datos/comentarios.csv", header=True,
                    inferSchema=True, encoding="UTF-8")

print("\nPRIMEROS COMENTARIOS")
df.show(5, truncate=False)
print("\nESTRUCTURA")
df.printSchema()
print("\nTOTAL")
print(df.count())

print("\nPOR RED SOCIAL")
df.groupBy("red_social").count().orderBy(desc("count")).show()

print("\nPRIORIDAD")
df.groupBy("prioridad_referencial").count().show()

resumen = (df.groupBy("red_social")
    .agg(count("*").alias("total"),
         spark_sum(when(col("spam_referencial") == "Sí", 1)
                   .otherwise(0)).alias("spam"))
    .withColumn("porcentaje",
                spark_round(col("spam") / col("total") * 100, 2)))
resumen.show()

df.createOrReplaceTempView("comentarios")
spark.sql("""
  SELECT red_social, COUNT(*) AS total
  FROM comentarios
  GROUP BY red_social
  ORDER BY total DESC
""").show()
spark.stop()
