MapReduce en tres momentos

El mapper convierte cada fila en un par como (Facebook, 1). Shuffle/Sort reúne las mismas claves. El reducer suma los valores y devuelve un conteo.

MapReduce in three stages

The mapper turns each row into a pair such as (Facebook, 1). Shuffle/Sort groups identical keys. The reducer adds the values and returns a count.

flowchart LR
  A[CSV] --> B[MAP]
  B --> C[Facebook, 1]
  B --> D[Instagram, 1]
  C --> E[SHUFFLE / SORT]
  D --> E
  E --> F[REDUCE: sum]

Laboratorio 1

Contar comentarios con Hadoop Streaming

El mismo CSV se procesa como texto y cada programa recibe datos por stdin y produce datos por stdout.

Lab 1

Count comments with Hadoop Streaming

The same CSV is processed as text; each program reads from stdin and writes to stdout.

1. Mapper

Lee la tercera columna, omite el encabezado y emite una unidad por comentario.

1. Mapper

It reads the third column, skips the header, and emits one unit per comment.

import csv
import sys

for line in sys.stdin:
    if not line.strip():
        continue
    row = next(csv.reader([line]))
    if len(row) < 3 or row[0].lstrip("\ufeff ").lower() == "id":
        continue
    network = row[2].strip()
    if network:
        print(f"{network}\t1")

2. Reducer

Hadoop ordena las claves antes del reducer. El programa acumula los valores mientras la red social sea la misma.

2. Reducer

Hadoop sorts keys before the reducer. The program accumulates values while the social network remains the same.

import sys

current = None
total = 0
for line in sys.stdin:
    parts = line.rstrip("\n").split("\t", 1)
    if len(parts) != 2:
        continue
    network, value = parts
    try:
        amount = int(value)
    except ValueError:
        continue
    if network != current:
        if current is not None:
            print(f"{current}\t{total}")
        current, total = network, 0
    total += amount
if current is not None:
    print(f"{current}\t{total}")

Limitación: el mapper procesa una línea a la vez. Las comas entre comillas funcionan, pero los saltos de línea dentro de una celda requieren otro formato o lector.

Limitation: the mapper processes one line at a time. Quoted commas work, but newlines inside a cell require another format or reader.

Parte II

¿Qué es Apache Spark?

Spark ofrece operaciones de alto nivel para leer, filtrar, agrupar y consultar datos con Python, SQL, Scala o Java.

Part II

What is Apache Spark?

Spark provides high-level operations to read, filter, group, and query data with Python, SQL, Scala, or Java.

Driver

Programa principal: crea la sesión y coordina el trabajo.

Main program: creates the session and coordinates the job.

Executors

Procesos que realizan tareas en un clúster.

Processes that perform tasks in a cluster.

Partitions

Partes lógicas que pueden procesarse en paralelo.

Logical portions that can be processed in parallel.

DataFrames

Un DataFrame es una colección con filas, columnas y esquema. Se parece a una tabla SQL o a pandas, pero Spark puede repartir su procesamiento.

A DataFrame is a collection with rows, columns, and a schema. It resembles a SQL table or pandas, but Spark can distribute its processing.

Transformaciones y acciones

Transformations and actions

filter, select y groupBy construyen planes. show, count y una escritura ejecutan el trabajo. Spark usa evaluación diferida en muchas transformaciones.

filter, select, and groupBy build plans. show, count, and a write execute the work. Spark uses lazy evaluation for many transformations.

df.count() devuelve un número; df.groupBy(...).count() crea un DataFrame agregado.

df.count() returns a number; df.groupBy(...).count() creates an aggregated DataFrame.

Lab 2

Analyze the CSV with Spark

DataFrames and Spark SQL express more questions without writing a dedicated reducer for each one.

from pyspark.sql import SparkSession
from pyspark.sql.functions import col, count, desc, sum as spark_sum, when

spark = (SparkSession.builder
    .appName("InstitutionalComments")
    .master("local[2]")
    .config("spark.sql.shuffle.partitions", "2")
    .getOrCreate())

df = (spark.read.option("header", True)
    .option("inferSchema", True)
    .option("encoding", "UTF-8")
    .csv("datos/comentarios.csv"))

df.printSchema()
df.show(5, truncate=55)
df.groupBy("red_social").count().orderBy(desc("count")).show()
df.groupBy("prioridad_referencial").count().show()

Porcentaje de spam por red

Comparar cantidades absolutas puede engañar: una red grande puede tener más spam simplemente porque tiene más mensajes.

Spam percentage by network

Absolute counts can mislead: a larger network may have more spam simply because it has more messages.

summary = (df.groupBy("red_social")
    .agg(count("*").alias("total"),
         spark_sum(when(col("spam_referencial") == "Sí", 1)
                   .otherwise(0)).alias("spam")))
summary.show()
